# 台本から音声ツール

要望と原稿を貼ると、Gemini が台本（話し手・1文ずつの行・声の案）にして、Gemini 3.8 Live か 3.8 TTS で音声にするツールです。HTML・CSS・JS だけで動きます（ビルド不要）。

## 使いかた

1. `index.html` をサーバーで開く（GitHub Pages など。`file://` では JS モジュールが読めません）
2. 「⚙ 設定」で Gemini APIキーを登録（このブラウザの localStorage にだけ保存）
3. 要望と原稿を貼って「台本にする」
4. 話し手ごとの声を確かめる（▶ 見本は同梱の WAV なので API を使いません）
5. 「出力する」→ 1文ずつ聞いて、直したい行は文を直して ↻
6. 速さ・文と文の間を決めて「全体をWAVで保存」か「1文ずつのWAVをZIPで保存」

## しくみ

| ファイル | 役目 |
| --- | --- |
| `js/core.js` | Gemini の呼び出し（台本・Live・TTS・文字起こし）と音の処理（無音の切り取り・つなぎ・速さ・切り分け）。DOM を使わないので Node 22 でも動く |
| `js/app.js` | 画面の動き。台本と設定は localStorage、作った音は IndexedDB に保存（再読み込みしても残る） |
| `js/voices.js` | Gemini の声 30種（性別・特徴） |
| `samples/` | 30種の声の見本 |

- **Live**: 1文ずつ別の接続で読む。読み上げを文字起こしして台本と比べ、合わなければ「」で囲んで3回まで作り直す。それでも合わない音は「要確認」にする（質問文に答えてしまうことがあるため）
- **TTS**: 1日10回までの無料枠に合わせ、並んだ行を2人ずつ・最大25文で1回にまとめて読み、文の終わりの長い間（`<long pause>`）で1文ずつに切る
- **速さ・間**: 作った音を作り直さずに、再生・書き出しのときに反映する（速さは音の高さを変えない WSOLA）

作りかたは nexmax-academy の音づくり（`scripts/lib/live_tts.ts`・`gemini_tts.ts`・`split_dialogue.ts`・`tempo.ts`）を写したものです。
